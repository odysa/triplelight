All **60 requests** pass the frozen primary, COUNT-compatible and value-compatible gates. **58 of 60** also have identical RDF-term bags. A primary pass includes the preregistered numeric tolerances; this is not a claim of exact RDF-term equality or global SPARQL conformance. This native output qualification reports no comparative execution-time result.

Both build input hashes agree, and its COUNT is 98,861,444. The clean build source is `7733eb4fbd0acb99832eea184ae340c96bea9a95`, with binary SHA-256 `73694951ae31723dc8ca4c4b6c7b5807f3892569dd389ec5cdb4950561ed2e56`. Every snapshot file was hashed before and after qualification and remained unchanged. No update or compaction interface was used.

The server ran on the Mac host with four Rayon threads and `--disk --cache-mb=10240`. The cache setting is not a process-memory limit or measured peak. Qualification began only after the server logged statistics readiness at 42.79 seconds. Raw HTTP elapsed observations are retained by the frozen collector, but this isolated native run is not a cross-engine comparison and contributes no performance table.
